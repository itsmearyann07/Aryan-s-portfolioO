# Here It Is — Aryan Singh Portfolio

This folder is a ready-to-deploy static website package. Keep `index.html`, `carousel.js`, `carousel.css`, `vercel.json`, and the included image/video files together at the root of the GitHub repository.

## Upload and deploy

1. Create a GitHub repository and upload the contents of this folder to its root.
2. Import that repository into Vercel. The included `vercel.json` serves the static site from the repository root; no build command is required.
3. The carousel is prebuilt in `carousel.js`, with its styles in `carousel.css`.

The website's local image/video assets are included beside `index.html`. The Hero, VFX, and AI Video Gumlet embeds stream from Gumlet.
